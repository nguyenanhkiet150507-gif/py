LÀNG PYTHON VUI VẺ - cấu trúc thư mục
index.html  : khung trang
style.css   : giao diện
games.js    : các trò chơi, đố vui, điểm sao
bai-tap.js  : DANH SÁCH BÀI TẬP (thêm bài mới ở đây)
runner.js   : chạy file .py trong trình duyệt
BT1.py BT2.py BT3.py : bài tập của bạn

Cách mở: mở terminal trong thư mục này, gõ  python -m http.server 8000
rồi vào http://localhost:8000 (lần đầu cần mạng để tải Pyodide).
